## 阻塞问题（P0）

### P0-1：文件上传缺少大小和类型校验

- **位置**：`ChatInput.vue:42-49`（handleFileUpload函数）
- **问题**：代码中有`// TODO: 检查文件大小和类型`注释，但未实现校验逻辑。用户可上传任意大小和类型的文件，可能导致：
  - 超大文件占用带宽和存储
  - 恶意文件上传风险
  - 后端返回错误时用户体验差
- **影响**：违反PRD FR-04业务规则第3条（图片10M/视频50M/音频100M/文档50M限制）
- **复现**：上传一个100M的图片文件，前端不拦截，直接提交
- **建议**：
```javascript
const FILE_LIMITS = {
  image: 10 * 1024 * 1024,
  video: 50 * 1024 * 1024,
  audio: 100 * 1024 * 1024,
  document: 50 * 1024 * 1024
}

function handleFileUpload(e) {
  const file = e.target.files[0]
  const fileType = getFileType(file.type) // image/video/audio/document
  const limit = FILE_LIMITS[fileType]
  
  if (!limit) {
    showError('不支持的文件格式')
    return
  }
  if (file.size > limit) {
    showError(`文件大小超限，最大支持${limit / 1024 / 1024}M`)
    return
  }
  // ... 后续逻辑
}
```

### P0-2：API调用缺少错误处理

- **位置**：`ChatInput.vue:65-72`（optimizePrompt）、`ChatInput.vue:74-84`（sendMessage）
- **问题**：
  - `optimizePrompt`没有try-catch，API失败时页面报错
  - `sendMessage`的catch只做了`console.log(e)`，用户无感知
  - 没有区分网络错误、业务错误、权限错误
- **影响**：用户发送消息失败后不知道发生了什么，可能重复发送导致消息重复
- **建议**：
```javascript
async function optimizePrompt() {
  if (!content.value.trim()) {
    showError('请先输入提示词')
    return
  }
  try {
    const res = await api.optimizePrompt(content.value)
    content.value = res.optimized_content
  } catch (e) {
    showError('优化失败，请重试')
  }
}

async function sendMessage() {
  if (!canSend.value || loading.value) return
  loading.value = true
  try {
    await chatStore.sendMessage({ content: content.value, files: files.value })
    content.value = ''
    files.value = []
  } catch (e) {
    showError(e.message || '发送失败，请重试')
  } finally {
    loading.value = false
  }
}
```

## 重要问题（P1）

### P1-1：Enter键发送未处理Shift+Enter换行

- **位置**：`ChatInput.vue:35-39`（handleKeydown）
- **问题**：按Enter直接发送，无法通过Shift+Enter换行。PRD明确要求"回车发送，Shift+回车换行"
- **建议**：
```javascript
function handleKeydown(e) {
  if (e.key === 'Enter' && !e.shiftKey) {
    e.preventDefault()
    sendMessage()
  }
}
```

### P1-2：缺少输入"/"唤起Skills面板功能

- **位置**：整个组件
- **问题**：PRD要求"输入/也可唤起同一面板"，但代码中只实现了点击Skills按钮唤起，未实现输入/唤起
- **建议**：监听textarea的input事件，当输入"/"且前面是行首或空格时唤起面板

### P1-3：缺少发送中loading状态，可能重复提交

- **位置**：`sendMessage`函数
- **问题**：没有loading状态，用户快速双击发送按钮可能重复发送消息
- **建议**：添加`loading` ref，发送期间禁用发送按钮并显示loading文案

### P1-4：fileInput ref使用方式不正确

- **位置**：`ChatInput.vue:22`（模板）、`ChatInput.vue:79`（script）
- **问题**：Vue 3中`$refs.fileInput.click()`应改为`fileInput.value?.click()`，且模板中ref绑定应为`ref="fileInput"`
- **当前代码**：模板中是`ref="fileInput"`，但script中用的是`$refs.fileInput`（Options API写法），与`<script setup>`不兼容
