## 一、背景与问题

UA超级入口是Under Armour面向企业办公场景的一站式AI智能助手。当前入口以单一聊天窗口为唯一交互载体，定位停留在基础问答，专业场景能力分散在HiAgent平台，用户需跨入口切换、操作割裂。

本次升级建设专属工作台，重构交互形态，将自然对话、智能体工具与可视化操作整合为一体化体验。工作台首页是用户落地的默认页面，承担自然对话、能力唤起、会话管理三大基础能力。

## 二、目标与非目标

### 目标

1. 建立统一入口，承接所有智能体的发现、唤起与继续对话
2. 用户登录后30秒内可完成首次AI交互
3. 智能体快捷入口点击率≥40%

### 非目标

1. 不包含各智能体独立页面的具体功能
2. 不包含Skills面板、历史对话详情、全部智能体弹窗的详细交互（独立需求）
3. 不包含后端智能体能力建设（HiAgent侧）
4. 不包含配置管理页和资产库管理页（仅白名单，独立需求）

## 三、用户与场景

### 用户画像

- **角色**：UA全体员工（市场、销售、设计、运营、HR等）
- **技术水平**：普通办公用户，非技术人员
- **使用频率**：日常高频使用

### 核心场景

1. **首次使用**：员工登录Lark，进入工作台，看到欢迎语，尝试输入问题或点击智能体
2. **日常使用**：员工进入工作台，从历史会话继续上次对话，或发起新对话
3. **能力发现**：员工通过快捷区或"查看全部"发现新的智能体能力

## 四、用户旅程

```
登录Lark → 进入工作台首页 → 浏览欢迎语和智能体快捷区
    ↓
    ├─ 直接输入问题 → 发送 → 进入对话详情
    ├─ 点击智能体pill → 进入独立智能体页
    ├─ 点击"查看全部" → 打开全部智能体弹窗 → 选择智能体
    ├─ 点击历史会话 → 进入历史对话详情
    └─ 点击"新对话" → 清空当前会话，回到空白输入态
```

## 五、功能需求

### FR-REQ-2026-001-01：顶部导航栏

**用户故事**：作为用户，我希望在顶部看到当前会话状态和免责声明，以便了解AI内容的性质。

**描述**：顶部导航栏固定在页面顶部，包含会话标题、免责声明和侧边栏开关。

**业务规则**：
1. 无历史消息时显示"新对话"，仅用于展示当前会话标题，不承担新建动作
2. 有历史消息时，顶部显示当前会话标题（取用户首条消息前20字，超长截断加省略号）
3. 统一免责声明：顶部固定展示"内容由AI生成，仅供参考"
4. 侧边栏开关：支持折叠/展开左侧会话栏

**验收标准**：
- Given 无历史消息 When 进入首页 Then 顶部显示"新对话"
- Given 任意页面 When 查看顶部 Then 始终显示"内容由AI生成，仅供参考"
- Given 点击侧边栏开关 When 会话栏展开 Then 会话栏折叠，主区占满
- Given 点击侧边栏开关 When 会话栏折叠 Then 会话栏展开

### FR-REQ-2026-001-02：左侧会话栏

**用户故事**：作为用户，我希望在左侧看到历史会话列表并能快速切换，以便继续之前的工作。

**描述**：左侧会话栏包含开启新对话按钮、历史对话列表、个人中心。

**业务规则**：
1. "开启新对话"位于会话栏顶部，点击后清空当前会话，回到空白输入态
2. 历史对话列表按最近消息时间倒序展示会话标题，支持滚动分页（每页20条）
3. 会话标题生成规则：取用户首条消息前20字，超长截断加省略号；无文本消息时显示"文件对话"
4. 点击列表项后，右侧切换为对应历史对话详情（不跳转新页面）
5. 折叠态：会话栏隐藏后，中央主区占满
6. 个人中心（会话栏底部）：展示当前登录用户头像与姓名
7. "配置管理"按钮仅对白名单用户可见，白名单在数据库中配置；白名单外用户看不到该按钮
8. 点击"配置管理"展开下拉菜单，包含"智能体配置"与"资产库管理"两项，分别对应不同白名单权限

**验收标准**：
- Given 有历史会话 When 进入首页 Then 左侧按时间倒序展示会话列表
- Given 点击"开启新对话" When 当前有会话内容 Then 清空当前会话，回到空白输入态
- Given 点击历史会话项 When 列表非空 Then 右侧切换为对应历史对话详情
- Given 白名单用户 When 查看个人中心 Then 可见"配置管理"按钮
- Given 非白名单用户 When 查看个人中心 Then 仅显示头像与姓名，无"配置管理"按钮
- Given 滚动到列表底部 When 还有更多历史会话 Then 自动加载下一页

### FR-REQ-2026-001-03：Hero标题区

**用户故事**：作为用户，我希望看到友好的欢迎语，以便了解这个工具能做什么。

**描述**：页面中央上方展示主标题和副标题。

**业务规则**：
1. 主标题："你好，我是你的/UA智能助手"
2. 副标题："释放创意生产力，实现视觉创作、专业翻译与协同办公一体化"

**验收标准**：
- Given 进入首页 When 无对话内容 Then 显示主标题和副标题
- Given 开始对话后 When 有消息内容 Then Hero区域上移缩小，保留主标题，副标题隐藏

### FR-REQ-2026-001-04：对话输入区

**用户故事**：作为用户，我希望在输入区输入文字、上传文件、调用Skill，以便与AI交互。

**描述**：输入区支持多行文本、文件上传、Skills唤起、优化提示词和发送。

**业务规则**：
1. 支持多行文本输入，回车发送，Shift+回车换行
2. 占位文案："输入业务消息、回车发送，支持直接上传表格，或者使用 / 调用核心技能。"
3. 文件上传限制：图片10M、视频50M、音频100M、文档50M，超限/格式错误由前端提示
4. 上传文件后以文件卡片形式展示在输入框上方，包含文件名、大小、类型、删除按钮；图片类文件支持缩略图预览
5. 点击"Skills"按钮展开Skills面板，输入"/"也可唤起同一面板，支持键盘上下选择和Esc关闭
6. "优化提示词"：对当前输入文本做AI优化，并直接回填输入框
7. 发送按钮：文本为空且无附件/任务配置时禁用，仅上传文件可发送

**验收标准**：
- Given 输入框为空 When 无附件 Then 发送按钮禁用
- Given 输入框有文字或有附件 When 点击发送 Then 提交对话
- Given 上传超过10M的图片 When 选择文件 Then 前端提示"文件大小超限"
- Given 输入"/" When 输入框聚焦 Then 展开Skills面板
- Given 点击"优化提示词" When 输入框有文本 Then 调用AI优化并回填输入框
- Given 按Esc When Skills面板展开 Then 关闭面板

### FR-REQ-2026-001-05：智能体快捷区

**用户故事**：作为用户，我希望在输入区下方看到常用智能体的快捷入口，以便快速进入。

**描述**：输入区下方横向平铺智能体pill，超宽时横向滚动，末尾有"查看全部"入口。

**业务规则**：
1. 展示方式：横向平铺智能体pill，超宽时横向滚动
2. 快捷区末尾展示分隔线+"查看全部"，点击打开全部智能体弹窗
3. 点击某个pill直接进入对应智能体独立对话/任务页，不混合当前上下文
4. 展示配置：快捷区展示哪些智能体由"智能体配置"中各智能体的"展示在首页"开关决定
5. 首页最多展示5个智能体，已达5个后再开启其他智能体的开关，提示"最多展示5个"，本次不生效
6. 排序规则：按"智能体配置"中的排序字段升序排列；未配置排序时按创建时间倒序
7. 空状态：无任何智能体开启"展示在首页"时，快捷区显示"暂无快捷智能体，点击查看全部"引导文案

**验收标准**：
- Given 智能体配置中开启了"展示在首页" When 进入首页 Then 对应智能体显示在快捷区
- Given 已开启5个智能体 When 再开启第6个 Then 提示"最多展示5个"，本次不生效
- Given 点击智能体pill When 快捷区非空 Then 进入对应智能体独立页面，不混合当前上下文
- Given 点击"查看全部" When 快捷区末尾 Then 打开全部智能体弹窗
- Given 智能体数量超过可视宽度 When 查看快捷区 Then 可横向滚动

## 六、状态与异常矩阵

### 页面状态

| 状态 | 触发条件 | 表现 |
|---|---|---|
| 空白态 | 新对话，无消息 | 显示Hero标题+空输入区+智能体快捷区 |
| 输入态 | 用户正在输入 | 输入框有内容，发送按钮可用 |
| 加载态 | 发送消息后等待回复 | 显示loading/打字机效果 |
| 错误态 | 发送失败/网络异常 | 显示错误提示+重试按钮 |
| 折叠态 | 侧边栏折叠 | 主区占满，侧边栏隐藏 |

### 异常处理

| 异常 | 处理方式 |
|---|---|
| 文件超限 | 前端拦截，提示"文件大小超限，最大支持XXM" |
| 文件格式错误 | 前端拦截，提示"不支持的文件格式" |
| 智能体列表加载失败 | 显示"加载失败"+重试按钮 |
| 历史会话加载失败 | 显示"加载失败"+重试按钮 |
| 网络断开 | 输入区禁用，提示"网络连接异常" |

### 权限矩阵

| 功能 | 普通用户 | 白名单用户 |
|---|---|---|
| 对话交互 | ✅ | ✅ |
| 查看智能体快捷区 | ✅ | ✅ |
| 查看历史会话 | ✅ | ✅ |
| 配置管理入口 | ❌ | ✅ |
| 资产库上传入口 | ❌ | ✅ |

## 七、非功能需求

### 性能
- 首页首屏加载时间 < 2秒（4G网络）
- 智能体列表接口响应时间 < 500ms
- 历史会话列表分页加载 < 300ms/页

### 安全与隐私
- 所有API请求携带Lark OAuth Token
- 用户对话内容加密传输（HTTPS）
- 不在前端存储敏感对话内容（仅存会话ID和标题）
- 文件上传前进行类型和大小校验

### 兼容性
- 支持Lark桌面端（Windows/macOS）和移动端（iOS/Android）
- 支持Chrome、Safari、Edge最新两个版本
- 响应式布局，适配不同屏幕尺寸

### 可访问性
- 所有交互元素支持键盘操作
- 图片有alt文本
- 颜色对比度符合WCAG AA标准

## 八、数据与埋点

### 埋点事件

| 事件名 | 触发时机 | 属性 | 用途 |
|---|---|---|---|
| page_view | 进入首页 | user_id, source | 首页访问量 |
| chat_send | 发送消息 | user_id, message_length, has_file | 对话发起率 |
| agent_click | 点击智能体pill | user_id, agent_id, position | 智能体唤起率 |
| view_all_agents | 点击"查看全部" | user_id | 全部智能体入口点击率 |
| skill_invoke | 输入"/"唤起Skills | user_id | Skills使用率 |
| optimize_prompt | 点击"优化提示词" | user_id, original_length | 优化功能使用率 |
| file_upload | 上传文件 | user_id, file_type, file_size | 文件上传统计 |
| new_chat | 点击"新对话" | user_id | 新对话发起率 |
| history_click | 点击历史会话 | user_id, session_age | 历史会话使用率 |
| sidebar_toggle | 折叠/展开侧边栏 | user_id, action | 侧边栏使用习惯 |

### 数据存储
- 历史会话列表：后端持久化，保留30天
- 用户偏好（侧边栏状态）：本地存储
- 白名单配置：数据库配置，接口下发

## 九、依赖与风险

### 依赖
1. HiAgent智能体列表API（提供智能体名称、图标、描述、是否展示在首页）
2. Lark OAuth登录鉴权
3. 对话服务API（UA智能助手Agent）
4. 文件上传服务

### 风险
| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 智能体列表API延迟 | 中 | 骨架屏+本地缓存+超时降级 |
| 白名单配置延迟 | 低 | 前端缓存+定期刷新 |
| 移动端适配问题 | 中 | 提前做移动端设计评审 |
